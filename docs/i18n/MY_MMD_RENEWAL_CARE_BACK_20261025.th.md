# MY MMD Renewal — ข้อความไทยที่แก้ตามเจ้าของ 25 ตุลาคม 2569

ข้อความประกอบการแก้หน้า Renewal ใน `MMD-Prive/mmd-workers` PR #2735 ต่อจาก PR #2733
เอกสารนี้เก็บข้อความไทยสำหรับทบทวนร่วมกัน ไม่สร้าง language engine ใหม่ ไม่เปลี่ยน loader และไม่ประกาศว่า dictionary rollout หรือ Production เสร็จแล้ว

## สมัครใหม่ — ระยะสมาชิกปกติ

| รายการ | ข้อความที่ใช้ |
| --- | --- |
| Premium | สมัครใหม่ 2,999 บาท / 2 ปี · ระยะสมาชิกปกติ |
| Standard | สมัครใหม่ 1,199 บาท / 1 ปี |

Premium สมัครใหม่ได้ 2 ปีตามแพ็กเกจปกติ ไม่ใช่ระยะต่ออายุ 1 ปี และไม่บวกโบนัสต่ออายุให้เป็น 3 ปีโดยอัตโนมัติ
ค่าสมัครใหม่เป็นข้อมูลเปรียบเทียบ ไม่ใช่ราคาต่ออายุของผู้ที่ยังไม่ถึงเกณฑ์

## CARE BACK — ข้อความประชาสัมพันธ์ในหน้า Renewal

- ชื่อส่วน: CARE BACK MEMBERSHIP
- หัวข้อ: ต่ออายุ 1 ปี รับเพิ่มสูงสุดอีก 1 ปี
- รายละเอียด: Standard เพิ่ม 180 วัน · Premium เพิ่ม 1 ปี เมื่อผ่านเงื่อนไข
- รอบประกาศ: รอบประชาสัมพันธ์ถึง 31 ต.ค. 2569
- ปุ่ม: อวยพรและดูสิทธิ์คูปองค่าบริการสูงสุด 10%
- หมายเหตุ: คูปองค่าบริการแยกจากค่าสมัครและค่าต่ออายุสมาชิก

ไม่เขียนวันสิ้นสุดสิทธิ์ภายในถึงสิ้นปีลงในข้อความลูกค้า ไม่ใช้คำว่า 5 วันสุดท้ายแบบคงที่
หลังช่วงประชาสัมพันธ์ ให้ซ่อนเฉพาะประกาศทั่วไป ไม่ตัดสิทธิ์ที่ backend ยืนยันจากการชำระที่เข้าเงื่อนไข
ปุ่มอวยพรเปิดหน้า Care เดิมภายใน MY MMD เท่านั้น ไม่ส่งคำอวยพร ไม่ออกคูปอง และไม่ลดค่าสมาชิกโดยอัตโนมัติ

## รายการต่ออายุที่ยืนยันแล้ว

| ช่อง | ข้อความ |
| --- | --- |
| ระยะพื้นฐาน | ระยะต่ออายุพื้นฐาน — 1 ปี |
| โบนัส | CARE BACK เพิ่ม — ใช้จำนวนที่ backend ยืนยัน |
| Premium ที่เข้าโปร | Premium · 1 ปี + 1 ปี / รวมระยะสมาชิก 2 ปี |
| Standard ที่เข้าโปร | Standard · 1 ปี + 180 วัน |
| วันเริ่ม | เริ่มต่ออายุ |
| วันหมดอายุใหม่ | ใช้ได้ถึงหลังต่ออายุ |

ต้องแยกระยะพื้นฐาน โบนัส และวันหมดอายุจริง ไม่ใช้ระยะสมัครใหม่แทนระยะต่ออายุ
หากไม่มีโบนัสในข้อเสนอที่ยืนยัน ห้ามเติมโบนัสเอง
ราคาต่ออายุ 1,000 / 2,500 บาทยังขึ้นอยู่กับเกณฑ์ที่เจ้าของกำหนด ไม่เพิ่มข้อยกเว้นยอดศูนย์หรือตั้งราคาเต็มแทนโดยอัตโนมัติ

## สถานะรอตรวจ

- กำลังตรวจประวัติเดิม ไม่ได้นับเป็นยอดศูนย์
- ประวัติเดิมยังตรวจไม่ครบ ให้เปอร์ตรวจสิทธิ์ให้ก่อน ไม่ได้นับยอดของคุณเป็นศูนย์
- ยอดที่ยืนยันได้ยังไม่ถึงเกณฑ์ราคาพิเศษ ให้เปอร์ตรวจราคาต่ออายุให้ก่อนนะครับ

การแก้ข้อความนี้ไม่ส่งผลต่อยอดเงินเดิม Points ประวัติย้อนหลัง หรือสถานะสมาชิก
